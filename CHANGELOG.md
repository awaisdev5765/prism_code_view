# Changelog

## 0.1.0

- Initial release.
- Built-in Dart, JSON, and YAML tokenizers with a pluggable
  `LanguageTokenizer` interface.
- `PrismCodeView` widget with line numbers, copy-to-clipboard button, word
  wrap, and a max-height scroll container.
- Adaptive light/dark palettes via `PrismCodeViewStyle`.
